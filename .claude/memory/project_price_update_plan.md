The price update pipeline is fully implemented and working.

**Entry point:**
```
python3 docs/items/scripts/run_pipeline.py [--lsb /path/to/LandSandBoat]
```
Full documentation: `docs/items/scripts/README.md`

**Key locations:**
- Scripts: `docs/items/scripts/` (8 Python scripts)
- Split CSVs (static, manually curated): `docs/items/csv/`
- Equipment level data: `docs/items/csv/equipment/`
- Master price file: `config/autoitem/items.csv`
- Skipped items report: `docs/items/price_update_skipped.md`
- Missing ingredients list: `docs/items/missing_ingredients.md`

**Important gotchas:**
- `update_prices.py` runs 3 times in the pipeline to fully converge cascading ingredient prices. Pass 1→2 changes ~565 items (mostly HQ +1 gear). Pass 2→3 changes 3 items. Pass 4 is identical to pass 3.
- Desynthesis recipes (lightning crystal id=4100 + single ingredient) are excluded from pricing to prevent circular dependency inflation. Without this, items like mythic_wand↔phoenix_feather, shofar↔behemoth_horn, galateia↔blessed_bliaut inflate exponentially across runs.
- If items.csv gets corrupted (prices in the billions), do `git checkout config/autoitem/items.csv` and rerun. Never run the pipeline multiple times on corrupted data.
- Row order in items.csv is manually curated — never reorder rows.
- 126 items are skipped due to missing ingredient prices or missing data. See `docs/items/price_update_skipped.md`. Adding missing ingredient prices to items.csv and rerunning will unlock dependent items.
- The split CSVs in `docs/items/csv/` are static and not regenerated by the pipeline. They were built manually and categorize items into pricing tiers.
- Legitimate outliers above 10M: plastron_+1 (~14.6M) and stout_kecks (~10.8M) — these are correct due to expensive HQ ingredients.
