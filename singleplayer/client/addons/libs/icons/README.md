# Status Icons — Attribution

The 32×32 `<id>.png` status-effect icons in this directory are used by the
autobots **Status** tab to render buff/debuff icons.

## Source & credit
Extracted and shared in PNG format by **Aricomfy** on the FFXIAH forums, as
freely-distributed fan content:

  https://www.ffxiah.com/forum/topic/55577/ffxi-status-icons-in-png-format/1/

Thanks to Aricomfy for doing the extraction and making these available to the
community.
