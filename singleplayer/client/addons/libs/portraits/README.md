# Character Portraits — Attribution

Face portraits used by the autobots **Create Char** tab to preview appearance.
Named `<race*100 + face>`, in three variants (`png_bg/`, `png_nobg/`, `jpg_bg/`);
the source images are kept as `.webp`.

## Source & credit
Sourced from the **Character Creation** article on Ffxiclopedia (the FFXI wiki),
and credited to its contributors for compiling and hosting these reference images:

  https://ffxiclopedia.fandom.com/wiki/Character_Creation

that license asks for. We converted the images (WebP → PNG / JPG) and produced
background-removed variants — those are derivative works.
